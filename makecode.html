Micro:bit

Environmental impact simulation based on temperature and renewable energy.

Information about the Micro:bit

The BBC micro:bit is used in this project as an embedded system for environmental monitoring and simulation. It contains a built-in temperature sensor, programmable buttons, LED display, and digital output pins.

In this project, the micro:bit collects temperature data and simulates environmental scenarios. The device acts as the physical input layer of the system, while the web interface handles data visualisation.

The micro:bit sends temperature values via serial communication to the browser, allowing real-time graphical representation.

Model Code (Makecode section)

The micro:bit was programmed using Microsoft MakeCode in Python mode. The program continuously reads temperature data from the internal sensor and updates the system state.

Two buttons simulate environmental changes:

- Button A increases the simulated temperature (representing increased emissions).

- Button B decreases the temperature (representing renewable energy usage).

A conditional structure checks whether the temperature exceeds 30°C. If this threshold is reached, a digital output activates an external LED as a warning indicator.

The system also sends temperature data through USB serial communication to be processed and displayed in the web interface.

serial.redirect_to_usb()

simTemp = input.temperature()
LIMIT = 30
PINO_LED = DigitalPin.P1  

def update():
    basic.show_number(simTemp)

    if simTemp > LIMIT:
        pins.digital_write_pin(PINO_LED, 1)
    else:
        pins.digital_write_pin(PINO_LED, 0)

update()

def on_button_pressed_a():
    global simTemp
    simTemp += 1
    update()

input.on_button_pressed(Button.A, on_button_pressed_a)

def on_button_pressed_b():
    global simTemp
    simTemp -= 1
    update()

input.on_button_pressed(Button.B, on_button_pressed_b)

def on_button_pressed_ab():
    global simTemp
    simTemp = input.temperature()
    update()

input.on_button_pressed(Button.AB, on_button_pressed_ab)
