Modelo Computacional em Python

Simulação de impacto ambiental baseado em temperatura e renováveis

Código do Modelo (Python)

Este modelo simples estima emissões de CO₂ ou impacto ambiental com base na percentagem de energias renováveis e temperatura média simulada.

import matplotlib.pyplot as plt
import numpy as np

# Dados base (exemplo: temperatura média vs emissões estimadas)
temperaturas = np.array([15, 20, 25, 30, 35, 40])  # °C
renovaveis = np.array([0, 20, 40, 60, 80, 100])   # %
emissoes = 120 - (renovaveis * 1.0) + (temperaturas - 20) * 2  # fórmula simples de exemplo

plt.figure(figsize=(10, 6))
plt.plot(renovaveis, emissoes, marker='o', color='red', label='Emissões com aumento de temp')
plt.axhline(y=60, color='orange', linestyle='--', label='Limite crítico (60 unidades)')
plt.title("Impacto das Energias Renováveis nas Emissões (influência da temperatura)")
plt.xlabel("Percentagem de Energias Renováveis (%)")
plt.ylabel("Emissões Relativas (unidades)")
plt.grid(True, alpha=0.3)
plt.legend()
plt.savefig("graficos/modelo_emissoes.png")
plt.show()

Interpretação: Quanto maior a percentagem de renováveis, menor o impacto das emissões, mesmo com temperaturas mais altas (cenário de aquecimento global). What-if: com 80% renováveis, emissões caem ~80% em relação ao base.

Análise e What-If Scenarios
  • Cenário base (0% renováveis, 20°C): Emissões altas (~120 unidades).
  • What-if +60% renováveis: Emissões caem para ~60 unidades (redução de 50%).
  • What-if temperatura +10°C: Aumenta emissões em ~20 unidades (efeito agravante do aquecimento).
  • O modelo usa uma fórmula linear simples para demonstrar relação inversa renováveis-emissões, influenciada pela temperatura coletada/simulada no micro:bit.
