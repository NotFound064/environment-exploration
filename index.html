Simulação de Temperatura e Impacto Ambiental

Leaving Certificate Computer Science 2026

micro:bit coleta/simula temperatura → LED alerta >30°C → dados enviados ao vivo para o browser (ou carregados de JSON manual).

Problem

O aumento da temperatura global causado por emissões de carbono é um problema ambiental significativo. Este projeto simula a recolha de dados de temperatura e analisa como ações humanas podem influenciar tendências climáticas.


Objetivo

Criar um sistema interativo que recolhe dados de temperatura, simula cenários ambientais e apresenta os resultados graficamente.


Inputs/Outputs

Inputs:
-Sensor de temperatura do micro:bit
-Botões A e B (simulação de emissões / energias renováveis)
-Inserção manual de dados no site
Outputs:
-Gráfico de temperatura
-Valor numérico da última leitura
-LED de alerta acima de 30 °C


Tecnologias Utilizadas

micro:bit (MakeCode)
HTML / CSS / JavaScript
Chart.js
Python 3.4


Conclusão

O sistema demonstra como sensores podem monitorizar condições ambientais. A simulação permite testar cenários (ex: aquecimento global). Limitações: sensor real varia pouco; melhorias: adicionar mais sensores (luz, humidade).
