Temperature and Environmental Impact Simulation

Leaving Certificate Computer Science 2026

The micro:bit collects or simulates temperature data → an LED alert is triggered above 30°C → data is displayed live in the browser or loaded manually from a JSON file.

Problem

The increase in global temperature caused by carbon emissions is a major environmental issue. This project simulates the collection of temperature data and analyses how human actions can influence climate trends.


Main Goal

To create an interactive system that collects temperature data, simulates environmental scenarios, and presents the results graphically.


Inputs and Outputs

Inputs:
– micro:bit temperature sensor
– Buttons A and B (carbon emissions simulation / renewable energy simulation)
– Manual data entry through the website

Outputs:
– Temperature graph
– Numerical display of the most recent reading
– LED warning light when temperature exceeds 30°C


Technologies Used

micro:bit (MakeCode)
HTML / CSS / JavaScript
Chart.js
Python 3


Analysis

The system demonstrates how sensors can be used to monitor environmental conditions. The simulation allows different scenarios to be tested, such as the effects of global warming.

Limitations: Real sensor variation is limited.
Improvements: Additional sensors such as light or humidity could be added.
